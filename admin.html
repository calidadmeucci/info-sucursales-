Conectar con GitHub

Este panel guarda los cambios directamente en el archivo data.json de tu repositorio, usando un token que generás vos mismo. El token queda guardado solo en este navegador — nunca se envía a ningún otro lado.

¿No tenés un token todavía? Generalo en github.com/settings/personal-access-tokens/new, elegí el repositorio y dale permiso de escritura sobre "Contents".
